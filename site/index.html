File shredder for Windows

Delete files so they stay deleted.

PermaDel overwrites files and folders with random data, flushes every pass to disk, then deletes them, so undelete and file-recovery tools have nothing to bring back.

What it does

Emptying the Recycle Bin only removes a file's entry. Its contents stay on the disk until something overwrites them. PermaDel does the overwriting, then removes the entry.

01

Every byte, every stream

Overwrites each file in place, including its NTFS alternate data streams, with random bytes from the Windows CSPRNG, and flushes every pass to the physical disk.

02

No trace in the metadata

Truncates each file to zero length, renames it to random names several times and resets its timestamps before deleting it.

03

Shred from File Explorer

Right-click files or folders and choose Shred with PermaDel. A submenu sets the number of passes and warns that the action is permanent.

04

Checks it's you

Optionally asks for Windows Hello or your account password before anything is shredded, so nobody else at an unlocked PC can use it.

05

Refuses what it shouldn't touch

Drive roots, Windows, Program Files, ProgramData, your user folders and PermaDel itself are refused, even when reached through a junction, a mapped drive or a short name.

06

Leaves other data alone

Links and junctions are removed without touching their targets. Hard-linked files and online-only OneDrive files are skipped instead of overwritten.

How it works

PermaDel scans the whole selection before it changes anything. Then, for each file:

  1. Clear attributes

    Read-only, hidden and system attributes are cleared. Files that can't be shredded keep their original attributes.

  2. Find every stream

    FindFirstStreamW lists all data streams, including alternate data streams that File Explorer never shows.

  3. Overwrite

    Each stream is overwritten in place with random bytes, once per pass, and FlushFileBuffers pushes every pass to the disk.

  4. Erase the metadata

    The file is truncated to zero length, renamed to random names several times and its timestamps are reset.

  5. Delete

    The file is deleted. Folders are scrubbed and deleted once they are empty, and anything that couldn't be shredded is reported with the reason.

Tested, and honest about limits

How it's verified

  • 33 unit tests cover long paths, lookalike names, junctions, hard links, locked files, online-only files and cancellation.
  • A forensic test shreds data on a raw NTFS virtual disk, then scans the disk image. No copy of the shredded contents remained.
  • The original file name remained only in the NTFS transaction log, which later file system activity overwrites.

What no file shredder can reach

  • SSDs and flash media. Wear leveling can put an overwrite in different cells. Use BitLocker from the start, or the drive's secure erase.
  • Copies elsewhere, such as shadow copies, backups, OneDrive, the page file and the hibernation file.
  • File system journals. The NTFS log and the USN journal can keep file names for a while.

Questions

Is PermaDel free?

Yes. PermaDel is free and open source under the MIT License. It has no ads, accounts or telemetry.

Does PermaDel work on SSDs?

It overwrites and deletes files on any drive, but no file-level shredder can guarantee destruction on SSDs, NVMe or flash media: wear leveling, TRIM and over-provisioning can put an overwrite in different cells than the original data. For SSDs, use full-disk encryption such as BitLocker from the start, or the drive's secure erase command when you retire it.

How many passes should I use?

PermaDel uses 3 by default and allows 1 to 35. NIST SP 800-88 considers a single overwrite pass enough to clear data on modern hard drives. More passes take longer.

Why does Windows SmartScreen warn about the installer?

The installer isn't code-signed yet. Compare its SHA-256 hash with the one on the release page (Get-FileHash in PowerShell), then choose More info and Run anyway.

Why does setup ask for administrator approval?

The File Explorer context menu needs a package that only an administrator can register. PermaDel itself runs as your user.

Does PermaDel collect any data?

No. PermaDel doesn't connect to the internet. Its settings are stored in the Windows registry under HKEY_CURRENT_USER\Software\PermaDel. See the privacy statement.

Get PermaDel

The installer adds PermaDel to the Start menu and, on Windows 11, to the File Explorer context menu. Uninstall it from Settings, Apps, like any other app.
